# Mob Presentation

Mob Skills 系列中的演示制作 Skill：从受众与证据出发，选择当前环境真实可用的制作工具，保留模板与可编辑对象，检查实际渲染结果，并在候选不达标时继续修正。

调用：`$mob-presentation`。它提供方法与路由，不自带 PPT 生成引擎，不捆绑公司事实、品牌素材或付费服务。

常见请求：

- “只改第 3 页标题，其他页面和备注保持原样，交付可编辑 PPTX。”
- “审阅这份合作演示，指出证据缺口与看不懂的关系，先不改稿。”
- “按给定模板做六页，图表保持原生可编辑，规划中的部署不能写成已经落地。”

入口见 [SKILL.md](SKILL.md)；制作工具与回退见 [tools](references/tools.md)，质量循环见 [quality](references/quality.md)。`SKILL.md` 与按需参考采用英文，便于跨宿主使用；输出语言遵从实际任务。

安装与包构建步骤见 [README](README.md#install-v010)。先使用固定版本安装到明确指定的项目测试目录，确认新会话实际发现；不替换正在运行的任务，不安装其他工具，不自动升级。原项目继续拥有任务编排、授权、事实、品牌、版本引用、验收与交付。

[来源比较](references/sources.md) 区分星数、实际更新和适用性；[验证记录](docs/validation.md) 区分包装检查与有限的路由演练。没有宣称制作质量已经通过多工具基准测试。
